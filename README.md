# Final del curso web, React + Vite
Una pequeña single page para practicar React + Vite

## Instrucciones para corre el proyecto
- Verificar que tenga node.js instalado: node -v
- Instalar las dependencias (usando --ignore-scripts para evitar la ejecución automática de scripts de instalación, como medida de seguridad frente a paquetes npm comprometidos): `npm ci --ignore-scripts`
- Si necesitás instalar nodemon como dependencia de desarrollo: `npm install --save-dev nodemon --ignore-scripts`
- Levantar el servidor de desarrollo: `npm run dev`
